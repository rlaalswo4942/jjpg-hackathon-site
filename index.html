JJPG 전주대 생활권 혼잡도 지도

다음 수업까지, 어디가 가장 낫습니까

전주대학교 생활권의 혼잡도를 블록 단위로 보여주고, 시간표를 등록하면 다음 수업 전 들를 만한 곳을 이동시간·대기·혼잡도까지 계산해 추천합니다.

루트 · React 19 · TypeScript · Leaflet · OSRM

Overview

다음 수업까지의 여정을 계산합니다

시간표 등록→ 다음 강의 탐색→ 출발지 확인→ 혼잡도 조회→ 대기·이용시간 추정→ 추천 순위 산정→ 보행 경로 안내
01

문제

01 공강 시간

도착해서야 만석을 안다

혼잡재이동

점심시간이나 짧은 공강에 식당·카페에 도착한 뒤에야 혼잡·만석을 알게 되고, 다시 다른 곳으로 이동하며 시간을 더 쓴다.
02 시간 판단

"갈 수 있는가"를 미리 알 수 없다

이동시간불확실성

가까워 보이는 곳이 다음 강의 건물과 반대 방향일 수 있고, 대기·이용시간까지 더하면 다음 수업에 늦을지 미리 판단하기 어렵다. 기존 지도는 위치와 리뷰는 보여줘도 "지금 실제로 이용하기 좋은가"엔 답하지 않는다.
02

솔루션

01 MVP

출발지 → 상가 → 다음 강의 건물, 전체 여정 계산

이동시간대기시간이용시간안전 여유시간

단순 최단거리 추천이 아니라, 상가에 들렀다가 다음 강의까지 갈 수 있는 전체 여정의 총 필요시간을 계산해 추천 순위를 정한다. 시간이 부족한 장소도 지우지 않고 점수만 낮춰 하위에 남긴다.
02 차별성

검증되지 않은 데이터는 넣지 않는다

OSMNominatimOverpass

있어 보이는 데이터보다 확인 가능한 데이터를 남긴다는 원칙으로 상호 16곳을 OSM·팀 상권조사·Nominatim 역지오코딩과 교차검증했고, 건물 284개는 단일 소스(campusBuildingFootprints.json)로만 관리해 좌표 불일치를 제거했다. 혼잡도·대기시간은 Mock 데이터이며 화면에 "시연" 배지로 명시한다.
03

핵심 기능

01 구현됨

혼잡도 지도

Leaflet6개 블록

생활권 상권 블록의 혼잡도를 지도 폴리곤과 목록 배지(여유=초록/보통=노랑/혼잡=빨강)로 표시한다.

자세히 보기 →
02 구현됨

시간표 & 다음 수업 추천

tesseract.jsOCR

시간표를 수동 입력하거나 이미지 업로드로 자동 인식하고, "다음 수업까지 갈 수 있는 곳"을 시간 여유 기준으로 추천한다. 캠퍼스 건물(강의동)은 추천 후보에서 제외된다.

자세히 보기 →
03 구현됨

실제 보행 경로 안내

OSRMrouting-machine

leaflet-routing-machine + OSRM 보행자 프로파일로 실제 경로를 계산한다. 장소를 선택하면 자동으로 목적지가 되어 경로가 그려진다.

자세히 보기 →
04 구현됨

자유 출발지 선택

GPSRouteOrigin

현재 위치 / 지도에서 선택 / 검색한 장소 / 캠퍼스 건물, 네 가지 출발지 중 선택 가능. GPS가 실패해도 조용히 대체하지 않고 실패 이유를 보여준다.
